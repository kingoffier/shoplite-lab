# ShopLite — учебный Git-репозиторий

Небольшой магазин на C# / .NET 8 для практики в Visual Studio: сумма заказа, доставка, купоны и VIP-скидка.

**Начните с [пошагового практикума](docs/LAB.md): действия в Visual Studio и команды Git для каждого этапа.**

## Что внутри

- Более 50 коммитов с историей разработки, слияний и исправлений.
- 13 веток: main, develop, feature/*, release/*, hotfix/*.
- 6 релизных тегов: v1.0.0 — v1.3.1.
- [История 12 локальных деплоев и одного rollback](docs/history/DEPLOYMENTS.md).
- [Разбор инцидента со скидкой](docs/incidents/INC-001.md), воспроизведение ошибки и исправление.
- Проверки приложения, GitHub Actions CI, скрипты сборки и локального деплоя.
- Задания: своя функция, коммиты, Push, PR или локальный merge, конфликт, релиз, деплой, откат.

## Клонировать и запустить

В Visual Studio: Continue without code -> Git -> Clone Repository ->
`https://github.com/kingoffier/shoplite-lab.git` -> выбрать папку -> Clone -> открыть ShopLite.sln.
Создавать новый проект или выполнять git init не нужно.

То же через терминал:

```powershell
git clone https://github.com/kingoffier/shoplite-lab.git
cd shoplite-lab
git branch -a
git log --all --graph --decorate --oneline
dotnet run --project src/ShopLite
dotnet run --project tests/ShopLite.Checks
```

Нужны Git и .NET SDK 8.x; для Visual Studio установите поддержку .NET 8.
Проверки — собственный консольный runner без внешних NuGet-пакетов.
Он возвращает ненулевой код при ошибке. `dotnet test` их не запускает.

## Где что смотреть на GitHub

- **Code / Branches** — ветки; переключатель ветки находится над файлами.
- **Commits** — история коммитов выбранной ветки.
- **Tags** — версии. Релизных тегов шесть; отдельные GitHub Releases пока не создавались.
- **Actions** — реальные запуски CI после публикации. Их результаты смотрите в самом запуске.
- **Pull requests** — место для ваших новых PR; исторические локальные merge-коммиты не создают прошлые PR.
- [Журнал локальных деплоев](docs/history/DEPLOYMENTS.md) — версии, UTC-время, commit SHA и rollback.

## Учебные условия

История создана для тренировки; авторы вымышлены, коммиты сделаны в одной сессии.
Локальные staging и production — папки с реально собранными и запущенными версиями,
а не облачные серверы. Публикация Git-истории не импортирует прошлые GitHub deployments или Actions runs.
Новые локальные сборки и окружения создаются скриптами в игнорируемой папке .lab.
Базовый smoke и существовавшие на v1.3.0 тесты намеренно пропускают учебный дефект;
отдельная бизнес-проверка обнаруживает его, после чего показаны rollback и hotfix.

Защиту веток и обязательные ревью при желании настройте в GitHub Settings отдельно.
Это один из возможных командных процессов, а не обязательная схема для каждой компании.
